# AI Study Assistant

## Project Title

AI Study Assistant

## Description

AI Study Assistant is a Generative AI based learning-support
application designed to help students understand academic subjects,
clarify doubts, revise concepts, and practice learning.

## Features

- Answer academic questions
- Explain difficult concepts
- Provide simple examples
- Generate study notes
- Help with programming questions
- Allow follow-up questions
- Provide easy-to-understand explanations

## Technologies Used

- Python
- Generative AI
- Google Gemini API
- Visual Studio Code
